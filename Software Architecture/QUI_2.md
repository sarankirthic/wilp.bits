# Software Architecture — Questions 1–15

## Question 1 — 0227

**Which of the following is NOT a common module structure?**

* a. Decomposition structure
* b. Client-server structure
* c. Layer structure
* d. Uses structure

**✅ Answer: b. Client-server structure**

---

## Question 2

**Allocation structures focus on:**

* a. How data is stored and accessed.
* b. How the system is divided into manageable units for development.
* c. How software elements interact at runtime.
* d. How software is mapped to hardware or organizational units.

**✅ Answer: d. How software is mapped to hardware or organizational units.**

## Question 6 — 0232
